\# Inventario de tienda de computadoras



Aplicación web para administrar los productos y el stock de una tienda de computadoras. Este proyecto servirá para practicar y aprender desarrollo web paso a paso.



\## Funcionalidades planeadas



\- Consultar los productos del inventario.

\- Buscar productos por nombre, marca o código SKU.

\- Filtrar por categoría y nivel de stock.

\- Agregar, editar y eliminar productos.

\- Registrar entradas y salidas de stock.



\## Tecnologías



\### Versión actual



\- HTML

\- CSS



\### Próximas etapas



\- JavaScript para agregar interactividad.

\- PostgreSQL para almacenar los productos.

\- Spring Boot para crear el backend.

\- Angular para construir la aplicación frontend.

\- Microservicios como etapa avanzada del proyecto.



\## Estado actual



La página muestra una interfaz estática con productos de ejemplo. La búsqueda, los filtros y los botones todavía no están conectados a JavaScript ni a una base de datos.



\## Cómo abrir el proyecto



Abre `index.html` en un navegador web.



\## Archivos



\- `index.html`: estructura de la página.

\- `styles.css`: estilos y diseño visual.

\- `README.md`: descripción y guía del proyecto.
